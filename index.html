3조 과제 지시서 — 가상 PoC · 실물 실증

시뮬레이터 열기1주차 과제2–4주차 과제

1주차는 가상 시뮬레이터 데이터로 온도 예측·이상감지 PoC 완료, 2–4주차는 같은 구조를 실물로 제작해 실증함. 두 단계의 CSV 형식이 같아서 1주차 모델을 실측 데이터에 그대로 적용하는 것이 핵심임.

일정 한눈에

1주차는 소프트웨어만으로 과업 전체 흐름을 한 번 완주하는 단계, 2–4주차는 그 흐름을 실제 장치 위에서 다시 돌리는 단계임.

주차 목표 산출물 완료 기준
1주차 · 가상 PoC 시뮬레이터 데이터로 예측·이상감지·제어 로직 검증 데이터셋(CSV), 노트북, 결과표, 5분 발표 테스트 MAE가 단순 기준선보다 낮음 · 팬 고장 구간 탐지
2–4주차 · 실물 실증 같은 구조를 실물로 제작, 실측 데이터 수집 후 1주차 모델 적용 장치 사진·배선도, 실측 CSV, 시뮬 대비 비교표, 제어 데모 영상 1 Hz 연속 수집 2시간 이상 · 목표 온도 유지 데모

공통 사항

시뮬레이터와 실물 장치는 같은 CSV 컬럼을 1초 간격으로 기록함. 컬럼명과 단위 변경 금지.

  • 시뮬레이터: 미니 리퍼 시뮬레이터 — 40 × 30 × 28 cm EPS 박스, TEC1-12706 펠티어, DS18B20 센서 3개 구성을 물리 모델로 재현
  • 화면 조작: 뚜껑 클릭 개폐, 화물 투입·반출(최대 16개), 팬 고장, 센서 드리프트, 배속 0–600×
  • 대량 생성: 오른쪽 [데이터 생성] 탭의 자동 생성(길이 6·24·72 h, 제어 방식, 시드, 고장 구간 포함 여부)
  • 권장 브라우저: PC 크롬 또는 엣지 (3D 화면 사용)
컬럼 내용 단위·값
ts 기록 시각 UTC ISO 8601
t_in_top 고내 상부 온도 ℃, 0.0625 단위 · 간헐적 빈칸(센서 누락)
t_in_bottom 고내 하부 온도 (화물 근처) ℃
t_ambient 외기 온도 ℃
door_open 뚜껑 열림 0 / 1
pwm 펠티어 구동 명령 0–255
current_mA 펠티어 전류 mA
voltage_mV 공급 전압 mV
mode 제어 방식 pid · hysteresis · manual
scenario 구간 태그 (정답 라벨) normal · door · load · ambient · fault

scenario는 시뮬레이터만 정답으로 기록함. 실물에서는 운용자가 실험 일지로 따로 남김.

담당 B 딥러닝 예측 모델, 예측 기반 제어 로직 실험 시나리오 운용, 실측 데이터 모델 적용, 제어 데모

1주차 — 가상 PoC

목표는 10분 뒤 고내 온도 예측과 고장 탐지를 시뮬레이터 데이터로 검증하는 것임. 장비 없이 과업 전체 흐름을 한 번 완주함.

1-1. 시뮬레이터 익히기

화면에서 직접 조작하고 센서 값이 어떻게 반응하는지 확인함. 관찰 내용은 한 줄씩 기록.

  • 뚜껑 60초 열기 → 상부·하부 온도 상승폭과 회복 시간
  • 화물 5개 연속 투입 → 하부 센서 변화, 상부와의 차이
  • 팬 고장 주입 → 온도 상승 속도, pwm·전류 변화
  • 제어 방식 pid ↔ hysteresis 전환 → 온도 파형 차이

1-2. 데이터 생성

세트 설정 개수 용도
A 정상 24 h · pid · 고장 없음 · 시드 1–5 5 학습(1–3) · 검증(4) · 테스트(5)
B 제어 비교 24 h · hysteresis · 시드 1–2 2 제어 방식이 바뀌어도 모델이 버티는지 확인
C 고장 72 h · pid · 고장 포함 · 시드 11–12 2 이상감지 평가
D 수동 화면에서 이벤트 직접 주입, 30분 이상 기록 1 현상 이해, 발표용 사례

파일명은 sim_<세트>_<시드>.csv 형식으로 통일.

1-3. 전처리·탐색

  • 센서 누락 빈칸: 짧은 공백은 선형 보간, 긴 공백 구간은 제외
  • 1초 데이터를 10초 또는 1분으로 다시 묶을지 결정 후 근거 기록
  • 특징 후보: 과거 값(1·5·10분 전), 이동 평균·기울기, pwm, door_open, t_ambient, 최근 10분 문 열린 시간
  • 그래프 3장: 하루 전체(온도·pwm), 문 열림 전후 확대, 고장 구간 확대

1-4. 예측 모델

예측 대상은 10분 뒤 t_in_top. 아래 세 가지를 같은 테스트 세트에서 비교함.

구분 모델 입력
기준선 현재 값 유지 (10분 뒤도 지금과 같다고 가정) 현재 온도
모델 A LightGBM 또는 RandomForest 1-3 특징
모델 B 1D-CNN 또는 GRU (작은 크기) 최근 30분 시계열 창
  • 학습·검증·테스트는 시드(파일) 단위로 분리. 시간 순서를 섞은 무작위 분할 금지(미래 정보 누수)
  • 지표: MAE(℃) 전체 + 문 열림·화물 투입 구간 MAE 별도
  • 모델 크기와 CPU 1회 추론 시간도 기록 (라즈베리파이 탑재 판단 근거)

1-5. 이상감지

  • 기본 방식: 예측 잔차(실측 − 예측)가 정해진 시간 이상 임계값을 넘으면 경보
  • 비교 방식(선택): Isolation Forest
  • 세트 C로 평가: 고장 시작부터 경보까지 지연(분), 정상 구간 하루당 오경보 횟수
  • 팬 고장과 센서 드리프트를 구분할 단서 정리 (드리프트는 상부 센서만 움직임)

1-6. 예측 기반 제어 로직 초안

  • 규칙 예: 10분 뒤 예측이 목표 + 2 ℃ 초과 → pwm 미리 상향, 문 열림 감지 → 즉시 최대
  • 오프라인 평가: 실제 8 ℃ 초과 사건마다 예측 경보가 몇 분 먼저 울리는지 계산
  • 실제 폐루프 적용은 2–4주차 실물에서 진행

1주차 제출물

  • 데이터셋 10개 (세트 A–D)
  • 노트북 (전처리 · 모델 A · 모델 B · 이상감지)
  • 결과표: 모델별 MAE, 구간별 MAE, 추론 시간, 탐지 지연·오경보
  • 5분 발표 (그래프 3장 + 결과표 + 제어 규칙 초안)

2–4주차 — 실물 실증

목표는 시뮬레이터와 같은 구조의 실물 장치로 같은 형식의 데이터를 수집하고, 1주차 모델과 제어 규칙을 실측에서 검증하는 것임. 3주를 한 단계로 묶되 주차별 진행은 아래 기준을 따름.

주차 진행 해당 항목 주차 말 확인
2주차 설계, 부품 수령, 조립, 단위 시험 2-1 ~ 2-3 센서 3개·리드 스위치·pwm 구동 동작
3주차 수집 로거 작성, 실측 시나리오 수집 2-4 ~ 2-5 시나리오 5종 실측 CSV 확보
4주차 시뮬레이터 대비 비교, 모델 적용, 제어 데모, 최종 정리 2-6 ~ 2-7 비교표·결과표·데모 영상

부품은 배송 기간을 감안해 1주차 중 주문 필요.

2-2. 설계

  • 배치도: 펠티어는 측벽에 40 × 40 mm 구멍을 내어 장착. 센서 위치는 시뮬레이터와 같게 (상부 뚜껑 아래 약 5 cm, 하부 바닥 위 약 2 cm, 외기는 박스 밖)
  • 배선도: 아래 장치 구성도 기준으로 GPIO 번호까지 표기
  • 안전 수칙
    • 고온측 팬이 돌지 않는 상태에서 펠티어 전원 인가 금지 (수 초 안에 과열·파손)
    • 펠티어 전류 경로는 굵은 선과 퓨즈 사용, 라즈베리파이 GND와 12 V GND 공통 연결
    • 첫 통전은 낮은 pwm부터, 저온측 결로가 전자부품에 닿지 않게 배치

장치 구성도

2-3. 조립·단위 시험

  • 센서 3개 값 동시 읽기 (실온에서 서로 0.5 ℃ 이내)
  • 리드 스위치 열림·닫힘 인식
  • pwm 0 → 64 → 128 → 255 단계별 전류·전압 기록
  • 고온측 방열판 온도 확인 (최대 출력 10분 후 손으로 만질 수 있는 수준)

2-4. 수집 로거

  • Python, 1 Hz, 공통 사항의 CSV 컬럼 그대로 기록
  • scenario 컬럼은 비워 두고 시작·종료 시각을 실험 일지에 기록 (나중에 라벨로 병합)
  • 장시간 수집 중 중단돼도 이어서 기록되도록 파일 이어쓰기

2-5. 실측 시나리오

시나리오 방법 시간
냉각 시작 실온에서 목표 5 ℃, pid 1–2 h
정상 유지 목표 도달 후 그대로 유지 2 h 이상
문 열림 60초 열기 3회, 20분 간격 1 h
화물 투입 실온 생수병 2개 투입 1 h
팬 정지 고온측 팬 5분 정지 후 복구, 방열판 과열 시 즉시 중단 30 min

2-6. 시뮬레이터 대비 비교

  • 냉각 곡선(목표 도달 시간), 문 열림 후 회복 시간, 정상 유지 평균 pwm을 시뮬레이터와 나란히 비교한 표
  • 차이가 큰 항목은 원인 추정 (단열, 펠티어 효율, 센서 위치 등)

2-7. 모델 적용·제어 데모

  • 1주차 모델을 실측 데이터에 그대로 적용한 MAE → 실측 일부로 재학습 후 MAE, 두 값 비교
  • 라즈베리파이에서 예측 기반 규칙 실행, 문 열림 시나리오에서 pid 단독과 비교 (8 ℃ 초과 시간)

2–4주차 제출물

  • 장치 사진, 배치도, 배선도
  • 실측 CSV + 실험 일지
  • 시뮬레이터 대비 비교표
  • 모델 적용 결과표 (그대로 적용 / 재학습)
  • 제어 데모 영상 (문 열림 시나리오)
